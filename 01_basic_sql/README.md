# 01 — Basic SQL

## Overview

This section contains SQL exercises covering fundamental database querying concepts using the Northwind sample database.

## Topics

- SELECT
- WHERE
- DISTINCT
- ORDER BY
- LIMIT / TOP
- AND, OR, NOT
- IN
- BETWEEN
- LIKE
- Aliases
- NULL values
- Basic date filtering

## Learning Objectives

- Retrieve specific information from database tables.
- Filter records using conditions.
- Sort and organize query results.
- Understand the structure of relational tables.
- Interpret SQL questions and translate them into queries.
- Explain and validate query results.
