# sql-learning-and-portfolio
## Project Goal

The goal of this project is to develop practical SQL skills and demonstrate the ability to understand database structures, translate business questions into SQL queries, analyze data, and validate results.

Through a structured collection of 100 SQL questions, ranging from beginner to advanced levels, I will strengthen my SQL knowledge while documenting each solution, explaining my reasoning, and demonstrating my problem-solving approach. This project aims to build a solid foundation for data-focused career opportunities.


## Objectives

- Understand relational databases and table structures.
- Write SQL queries to retrieve and filter data.
- Work with sorting, grouping, and aggregate functions.
- Understand and apply different types of JOINs.
- Work with dates, strings, and conditional logic.
- Use subqueries, CTEs, and window functions.
- Understand primary keys, foreign keys, and database relationships.
- Validate query results and explain the reasoning behind solutions.

## My Learning Methodology

For each SQL exercise, I aim to document:

1. **Business Question:** What problem are we trying to solve?
2. **Database Structure:** Which tables and columns are relevant?
3. **SQL Solution:** What query answers the question?
4. **Reasoning:** Why did I choose this approach?
5. **Alternative Approaches:** Are there other valid ways to solve it?
6. **Validation:** How can I verify that the result is correct?
7. **Lessons Learned:** What did I learn from the exercise?

## Important Learning Principle

Writing a query is only part of solving a database problem.

I also focus on understanding the database schema, selecting the correct columns, interpreting results, identifying limitations, and explaining why a particular solution works.

I use AI tools as learning and productivity assistants, but I review the SQL logic, check compatibility with the database schema, and validate the results myself.
